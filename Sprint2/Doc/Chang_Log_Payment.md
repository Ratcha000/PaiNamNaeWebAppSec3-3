
## 2026-03-01
- **การปรับปรุง UI**
  - ปรับการแสดงผลข้อมูล OCR ใน `frontend/pages/payment/driver.vue` ให้แสดงสถานะการตรงกันของจำนวนเงินและจัดการกรณี OCR ล้มเหลว จิตรานุช
  - ปรับข้อความแจ้งสถานะการชำระเงินให้แสดงตามวิธีการ (เงินสด, QR, โอนผ่านธนาคาร) อย่างชัดเจน ชนันกานต์
  - ทำให้หัวข้อโมดัลตรวจสอบและข้อความตัวอย่างในช่องกรอกข้อมูลเปลี่ยนตามการยืนยันหรือการปฏิเสธ จิตรานุช และ ชนันกานต์
- **การปรับปรุง Backend**
  - เชื่อมต่อบริการ OCR (`services/ocr.service.js`) กับขั้นตอนอัปโหลดใบเสร็จ รัชช
  - เพิ่มการอัปโหลดรูปภาพใบเสร็จไปยัง Cloudinary (`utils/cloudinary.js`) รัชช
  - ปรับ schema การตรวจสอบให้รวมข้อมูลเมตาดาต้าใบเสร็จ รัชช
- **ฟีเจอร์ใหม่**
  - เพิ่มหน้าจัดการ QR Code และข้อมูลธนาคารของคนขับ (`frontend/pages/driver/qrCode.vue`) จิตรานุช ชนันกานต์
  - เพิ่ม endpoint API สำหรับ QR Code และข้อมูลธนาคารใน `backend/src/routes/payment.routes.js` รัชช
  - ขยาย composable `usePayment.js` ให้มีฟังก์ชันดึง QR Code และอัปเดตข้อมูลธนาคาร จิตรานุช ชนันกานต์
- **การแก้บั๊ก**
  - แก้กรณีที่การดึงข้อมูลจาก OCR คืนค่า `null` ทำให้ UI ค้าง จิตรานุช ชนันกานต์
  - แก้ปัญหาการชนกันของเมนูใน `layouts/default.vue` หลังรวมลิงก์ของ driver payment รัชช
